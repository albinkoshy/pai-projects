# Probabilistic AI Projects (Autumn 2023)

Group projects, which is part of the Probabilistic Artificial Intelligence Course at ETH taught by Prof. Andreas Krause from the Learning & Adaptive Systems Group.

## Project 1: Gaussian Processes
Implementation of Gaussian Process Regression for air pollution prediction.

## Project 2: Bayesian Neural Networks
Bayesian Neural Network using approximate inference via [SWA-Gaussian (SWAG)](https://arxiv.org/pdf/1902.02476.pdf) and calibration methods to minimize ECE error.

## Project 3: Bayesian Optimization
Finding best drug candidate which maximizes the candidate's corresponding bioavailibility (logP) while satisfying a constraint on synthesizability. Bayesian Optimization using Upper Confidence Bound (UCB) acquisition functions.

## Project 4: Reinforcement Learning
Solving the inverted pendulum problem using the off-policy Soft Actor Critic RL algorithm.
